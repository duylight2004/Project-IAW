Race Condition — TOCTOU

Server co window 250ms giua READ va WRITE. Gui 2 request dong thoi se khai thac TOCTOU:

  • T+0ms — Request A: SELECT status='open' ✓
  • T+10ms — Request B: SELECT status='open' ✓ (A chua UPDATE)
  • T+250ms — Request A: UPDATE settled + INSERT settlement #1
  • T+260ms — Request B: UPDATE settled + INSERT settlement #2 → FLAG!
Luu y: Bam Settle Bid tren giao dien chi gui 1 request tuan tu. De khai thac thanh cong TOCTOU và lay FLAG, ban can su dung tool hoac script (Python/Burp) de gui 2 request dong thoi trong window 250ms. Neu he thong da settle roi, bam Reset DB truoc khi thu lai.
